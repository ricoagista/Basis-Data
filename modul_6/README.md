## 📌 Konsep yang Dicakup

| Konsep | Keterangan |
|--------|-----------|
| `INNER JOIN` | Menggabungkan baris yang cocok di kedua tabel |
| `LEFT / RIGHT OUTER JOIN` | Menyertakan semua baris dari satu sisi |
| `FULL OUTER JOIN` | Menyertakan semua baris dari kedua tabel |
| `Sub Query` | Query di dalam query (WHERE, FROM, SELECT) |
| `VIEW` | Tabel virtual berdasarkan hasil SELECT |

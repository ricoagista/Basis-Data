# Modul 5 — Aggregate Function

Fungsi agregat SQL: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, pengelompokan data dengan `GROUP BY`, dan filter agregat dengan `HAVING`.

## 📌 Konsep yang Dicakup

| Fungsi | Keterangan |
|--------|-----------|
| `COUNT()` | Menghitung jumlah baris |
| `SUM()` | Menjumlahkan nilai kolom |
| `AVG()` | Rata-rata nilai kolom |
| `MIN()` / `MAX()` | Nilai minimum / maksimum |
| `GROUP BY` | Mengelompokkan hasil query |
| `HAVING` | Filter kondisi pada hasil GROUP BY |
